A one-line excuse a gamer texts the boss to skip work during GTA 6 launch week: fire alarm testing all morning, desk right under the speaker, can I work from home today? A boring, specific workplace detail a tired manager would almost believe — no dead grandmother, no flat tyre, no sudden fever.

## Run it

```sh
python3 main.py
```

Writes the single-line excuse (97 characters, 18 words) to `/output/entry.txt`. Fully deterministic: no randomness, no clock, no network, no input files. The program self-checks the gate (1–140 characters, one line, at most 20 words, no cliché excuse words) and re-reads the file it wrote to prove it landed byte for byte.
